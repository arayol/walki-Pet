
# Shared Components & Utilities

Esta pasta contém todos os componentes, hooks e utilitários compartilhados entre as diferentes aplicações.

## Estrutura:
- `components/ui/` - Design system (Button, Card, etc.)
- `hooks/` - Hooks compartilhados (useAuth, useToast, etc.)
- `services/` - Serviços do Supabase e APIs
- `types/` - Interfaces e tipos TypeScript
- `utils/` - Utilitários gerais
